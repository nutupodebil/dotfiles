
These are my strange and perhaps silly dotfiles.

## General
All file and directory names that start with the prefix `dot-` correspond to files in your system’s home directory if you replace this prefix with `.` :
for example, the `dot-scripts` directory corresponds to the `~/.scripts` directory.


## Installation
First, make sure you have `git` installed (and make sure that you generally have all necessary packages listed in `packages-list.md`).
Otherwise, install them with:
```shell
sudo pacman -Syu git
```

Then clone this repository into the `~/.dotfiles` directory (or any other directory that is strictly one level below the home directory `/home/your-user`):
```shell
mkdir ~/.dotfiles
git clone https://github.com/nutupodebil/dotfiles.git ~/.dotfiles
```


## Setup
Or you can simply run the setup scripts located in the `~/.dotfiles/dot-scripts/setup-scripts` directory:

### 1. `setup.sh`
```shell
sh ~/.dotfiles/dot-scripts/setup.sh
```
This script will create all the necessary directories in `~/.config` (*to avoid problems with symlinks*),
install **yay**, rebuild the `get_backlight_device` script and install all the required packages and **Hyprland** plugins listed in `packages-list.md`.

There are also the scripts `install-optional.sh`, `setup-monitors.sh`, `install-zsh.sh` and `install-fish.sh`.

### 2. `install-optional.sh`
```shell
sh ~/.dotfiles/dot-scripts/install-optional.sh
```
This script will install all optional packages listed in `packages-list.md`:

### 3. `setup-monitors.sh`
First, modify the *ac* and *battery* configs to match your monitors, along with `hyprmoncfg`.

Then it will be enough to simply run `setup-monitors.sh`:
```shell
sh ~/.dotfiles/dot-scripts/setup-monitors.sh
```
*Note*: you can learn more about **`hyprmoncfg`** by following the link: https://hyprmoncfg.dev/what-is-hyprmoncfg/

### 4. shell
There are two scripts, `install-zsh.sh` and `install-fish.sh`, which can help you install **`zsh`** or **`fish`** shell.

The first one will change the shell to **zsh** and install **oh-my-zsh** along with **powerlevel10k** zsh theme:
```shell
sh ~/.dotfiles/dot-scripts/install-zsh.sh
```
*Note*: if you’re going to use **zsh** instead of **fish**, be sure to comment out the line "shell /usr/bin/fish" in `~/.dotfiles/dot-config/kitty/kitty.conf`.

The second one will install **fish** with **fisher** plugin manager and **tide** plugin for for customize your prompt:
```shell
sh ~/.dotfiles/dot-scripts/install-fish.sh
```

## Final steps
Go to the `~/.dotfiles` directory and invoke **`stow`** with the following flags:
```shell
cd ~/.dotfiles
stow --dotfiles .
```


## Important additions
### 0. `stow` problems
`stow` will return an error if there are files (not symlinks) with the same names as the files in this repository in your home or `~/.config` or `~/.scripts` directories.
*Note*: you can read more about **GNU Stow** by following the link: https://www.gnu.org/software/stow/manual/

### 1. Waybar
A special font is used for Waybar; it contains many beautiful icons representing various programs and applications.
You can use the already compiled .ttf file located in `dot-local/share/fonts/` or compile the font yourself using:
```shell
sh ~/.dotfiles/dot-scripts/setup-scripts/compile-font.sh
```
*Note*: link to the repository with the font is in the "links" section below.

### 2. `hypr-refresh.sh` script
For the correct operation of the script `hypr-refresh.sh` (changes the monitor refresh rate),
it is necessary to enable tracking changes in the `/var/lib/power-profiles-daemon/state.ini` file with:
```shell
systemctl --user daemon-reload
systemctl --user enable --now hypr-refresh.path
```

### 3. `get_backlight_device` script
It is also highly recommended to rebuild the `get_backlight_device` script yourself (the source code is at `dot-scripts/src/` dir).
I used the following commands to compile:
```shell
cd ~/.dotfiles/dot-scripts
clang++ --std=c++20 -O3 -fsanitize=address,undefined -Wall -Wextra -Werror ./src/get_backlight_device.cpp -o get_backlight_device
```
*Note*: if you ran the `setup.sh` script earlier, these steps have already been done for you.

### 4. Zen Browser
To apply the color palette generated by **matugen** in **Zen Browser**, follow the steps described [**here**](https://github.com/InioX/matugen-themes#zen-browser)
